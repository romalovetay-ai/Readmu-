# Автопостинг в @CHEPOBABKAMOFF

Источники тем: `sources.txt` (чужие каналы, только читаем). Публикуем только в свой канал через бота @Claudep2121ost_bot.
Токен: переменная `TELEGRAM_BOT_TOKEN` (в файлы и git не писать).

## Один запуск

1. `python3 tg.py sync` — опубликовать черновики, которые одобрены кнопкой ✅, затем `python3 tg.py dedupe` — удалить дубли в канале.
2. `python3 fetch.py --mark-seen` — свежие посты источников в `out/candidates.json`.
3. Выбрать 1 тему (`posts_per_run` в `config.json`):
   - только деньги: зарплаты, цены, ипотека, вклады, налоги, банки, комиссии, пенсии, работа;
   - не брать: политику, задержания, войну, болезни, криминал, рекламу, шоу-бизнес без денег;
   - не повторять темы из `state/log.json`.
4. Написать пост с нуля голосом канала «Чё по бабкам»:
   - жирный заголовок-хук с цифрой, 3–6 коротких абзацев, немного мата, эмодзи в меру;
   - своя мысль: сравнение, расчёт или «что с этим делать»;
   - в конце вопрос к подписчикам;
   - не копировать фразы источника, не упоминать и не ссылаться на чужой канал;
   - цифры перепроверить; не уверен — не писать;
   - Telegram HTML (`<b>`, `<i>`), до 1024 символов → `out/post.html`.
5. Картинка: `python3 card.py --big "<цифра>" --sub "<подпись>" --pose <поза> --emo <эмоция> --color <цвет> --out out/card.jpg`.
   Чужие картинки не использовать. Посмотреть результат перед отправкой.
6. `python3 tg.py post --photo out/card.jpg --text out/post.html` (в режиме draft уходит в личку на одобрение).
7. Дописать в `state/log.json` `{date, source, title}`, закоммитить `state/` и запушить.
