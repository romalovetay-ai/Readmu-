# Стандарт канала «ЧЁ ПО БАБКАМ» (утверждено 2026-11-15)

Всё ниже утверждено пользователем на демо «шаурмичная Васи» (`videos/invest/demo.py`). Новые ролики делаются по этим параметрам; менять — только по явной просьбе.

## Картинка: 2D-рисовка (не 3D)
- Код: `videos/invest/art.py` (кит объектов), `videos/invest/world.py` (локации), `videos/invest/scenes2d.py` (сцены и компоновщик), `videos/invest/demo.py` (образец «истории в локации»).
- Стиль объектов (`art.shape`): заливка с мягким вертикальным градиентом + cel-тень (серп со стороны, противоположной свету) + блик по краю + обводка цвета `INK (0.13, 0.06, 0.15)` толщиной `LW = 5` px (как у ведущего) + мягкая контактная тень `art.ground`.
- Палитра `art.P`: gold (1.00, 0.78, 0.28), green (0.36, 0.80, 0.52), red (0.95, 0.34, 0.37), blue (0.38, 0.56, 0.96), purple (0.62, 0.42, 0.95), amber, cream, steel, wood. Акции = purple, облигации = blue, фонды = green, золото = amber.
- Заголовки-наклейки `art.title / art.pop_title`: толстая обводка INK, тень со сдвигом, двухтоновая заливка с бликом; появление с овершутом (0,38 с).
- Фон по умолчанию — `art.background`: бордово-индиговая стена, мягкие пятна, вращающиеся скруглённые квадраты (мотив канала), город на горизонте с окнами, пол с бликом. Горизонт `FLOOR = 800`, объекты стоят на `GY = 900`.
- **Локации вместо одной студии**: на каждую главу — своя нарисованная локация (как улица с шаурмичной в `world.py`): небо, облака, дальние дома (параллакс 0.35), ближние дома (0.7), улица/объекты (1.0), фонари, деревья. Сквозной персонаж-история (Вася) лучше голых схем.
- **Одна непрерывная камера** по ключам `(время, (cx, cy, zoom))` с ease-in-out между ними — без жёстких склеек внутри главы; открытие главы — спуск с неба / затемнение из чёрного.
- Анимация: squash & stretch при приземлении (`world.squash`, 0,35–0,45 с), замах и follow-through, вторичное движение (пар, монеты, облака, флажки), счётчики цифр «на глазах».
- **Слова в такт голосу**: ключевые слова выскакивают в момент произнесения (по таймингам слов Whisper), предыдущее уезжает вверх и гаснет за 0,18–0,22 с.
- Пост: `cine.post(..., bloom=0.16–0.18, grain=0)` — без плёночного зерна (чище и лучше сжимается).
- 1920×1080, **60 к/с**.

## Ведущий: версия v2 (`videos/narrator/approved/v2/`)
- Внешность прежняя (v1), не менять: блондин с рваными волосами, тату WUZI на шее, серьги-гвоздики, тёмная футболка, «MONEY»/«TALKS» на руках.
- В кадре с речью — **только `narrator.perform_v2(t, level, words, lt, pose, emo, seed, body_level=...)`**:
  - рот по звукам из таймингов слов (виземы A, O, U, E, I, M/Б/П — сомкнуты, F/В — зубы, C), форма рта усредняется по окну ~80 мс — плавно перетекает;
  - жест держится ~4,2 с и перетекает за 1,4 с, плечо ведёт, кисть догоняет (overlap, follow-through 0,05);
  - эмоция кроссфейдится за то же время (никаких скачков в паузах);
  - на словах — мягкие акценты: кивок до 3,5 px, брови 0,2, жест 0,35 (плавный набор 0,14 с, затухание ×3/с);
  - `body_level` — громкость, сглаженная окном 0,35 с (руки не дёргаются от слогов);
  - **руки никогда не закрывают лицо**: позы `facepalm` и `think` в v2 заменяются (`FACE_FREE`), жесты из `GESTURES_V2` (explain, point, shrug, cross);
  - моргание нерегулярное (2,2–5,5 с, иногда двойное).
- Позиции: сбоку x=1600–1610, base=H+6, scale=0.56; средний план 960 / H+40 / 0.70; крупный 960 / H+92 / 1.0. Мягкая тень `cine.drop_shadow(-36, 6, 22, 0.42–0.45)`.

## Крик
- `art.shout_fx(..., layer="back")` до ведущего и `layer="front")` после:
  - затемнение краёв с тёмно-бордовым оттенком (центр чистый);
  - манга-линии концентрации на голову ведущего (64 шт., медленно вращаются, «кипят» ~4 раза/с, подтягиваются на громких словах);
  - мягкие волны-кольца от ведущего на сильных словах.
- Камера: плавный наезд +3,5 % и лёгкое покачивание, **без тряски**, без сплошной красной заливки. Лицо на всю фразу — `angry` (не переключать).

## Озвучка: версия v2 (по умолчанию `VOICE_V=2` в `videos/invest/build.py`)
- Голос: F5-TTS, образец `videos/narrator/voice/ref.wav` (CC0).
- Модель по стилю: calm → `podcaster`; joke и shout → `emotional`.
- Генерация целыми фразами (куски до 170 символов), `nfe=32`, до 4 попыток с проверкой Whisper (порог 0,9), паузы между кусками 0,28 с.
- Скорость: calm 0,98, joke 1,04, shout 1,08.
- Ударения: RUAccent + `STRESS_FIX` в `voice/f5.py`; аббревиатуры через `SAY_FIX` в `build.py` (ЦБ, ОФЗ, ИИС…); числа в тексте — словами.
- Студийная обработка `POST_V2`: highpass 75 Гц, afftdn −28, −2,5 дБ на 250 Гц, +3 дБ на 3,2 кГц, +2 дБ на 9,5 кГц, de-esser 0,4, компрессор 3:1 (−20 дБ), лёгкая комната (aecho 24/37 мс, 0,05/0,03), loudnorm −16 LUFS.
- Крик `POST_V2_SHOUT` — **чистый**: без exciter, без сдвига тона, без эха; highpass 85, afftdn −30, EQ −2,5 дБ@250 / +2,5 дБ@2,8 кГц, de-esser 0,5, компрессор 4:1, limiter, loudnorm −15 LUFS.

## Звук
- Музыка: процедурный lofi (`music.lofi`), дакинг под голос до 0,42.
- SFX на каждое действие (`demo.sfx_lib`): звон монет, pop, whoosh, thud (печать), sparkle (конфетти), tick, ding, rise (рост), crack, splash, гром + шум дождя.
